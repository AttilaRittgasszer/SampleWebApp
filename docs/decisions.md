# Decision log

## Initial decisions

- Use public GitHub repository with public-safe rules.
- Use pnpm as package manager.
- Use Next.js App Router, React, and TypeScript.
- Use Tailwind CSS and shadcn/ui.
- Use GitHub Actions only on `main` and manual dispatch for cost control.
- Use local `.env.local` and Vercel Environment Variables for secrets.
- Keep the app portable for a later Google Cloud Run migration.
